# Repair Routing Reference

| Failure | Owner | Allowed action |
| --- | --- | --- |
| unsupported/contradicted/uncertain factual evidence | Research Orchestration | repair evidence/provenance for affected claims |
| factual narration mismatch | Script Agent | rewrite affected narration while keeping approved claim IDs |
| narration redundancy | Script Agent | local pacing/wording rewrite |
| pedagogical structure/progression | Pedagogy Agent | replan affected pedagogical scope |
| semantic visual mismatch/modality | Visual Director | regenerate semantic visual intent/SceneGraph structure |
| deterministic geometry/render QA | Core Repair | deterministic/local repair |
| supported scene-critic patch | Core Repair | selective typed patch |
| video pacing/transition mechanics | Core Repair | deterministic temporal/transition repair |
| strict critic outage / invalid response | no invented owner | block according to authoritative QA policy |

Core-owned work never becomes an LLM repair task.
