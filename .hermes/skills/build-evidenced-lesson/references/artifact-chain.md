# Accepted LearnFlow Artifact Chain

Use this reference to verify that a complete lesson followed the accepted boundaries.

## Typed progression

```text
LearningBrief
→ ResearchPack + EvidenceGraph
→ FactVerificationReport
→ PedagogyPlan
→ LessonScript
→ deterministic ConceptRegistry
→ Storyboard + SceneGraph[]
→ Core layout/motion/render artifacts
→ authoritative scene/video QA
→ Agent-Aware routing when needed
→ final video + manifests
```

## Required ownership

| Concern | Owner |
| --- | --- |
| research strategy and evidence collection | Research Orchestration |
| deterministic factual eligibility | Fact Verification |
| objectives, examples, concept progression | Pedagogy Agent |
| spoken/subtitle narration | Script Agent |
| semantic visual intent and SceneGraph structure | Visual Director |
| geometry, layout, timeline arithmetic, renderer pixels | Core V2 |
| issue ownership after QA | Agent-Aware QA |
| cost/retry accounting and publication policy | Runtime Governance |

## Stop conditions

Do not advance when the current deterministic gate is not ready. Do not transform a blocked artifact into an apparently valid downstream artifact by dropping IDs, rewriting provenance, or changing ownership.

## Production activation

Project-local skills are trusted procedure inputs. Production operators must review these skill files and explicitly trust the repository before project-skill discovery is enabled.
