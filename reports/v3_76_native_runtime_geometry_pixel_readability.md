## Root causes and actual existing pipeline

V3-75 succeeded on two of three original V3-54 mock model-shaped creative Storyboards but exported conservative estimated bounding boxes rather than Manim runtime Computer Modern glyphs. That cannot conclusively identify score-label collisions. Independently observed decoded native frames included low-contrast text and sparse visual hierarchy. A native H264 temporal pixel proxy is not readability proof, and static source geometry cannot certify `Indicate` intermediate states.

The V3-51 host compiler instantiates actual Manim `Text`, `RoundedRectangle`, `Rectangle`, and `VGroup` objects before its first animation command. In the new strict-only integration, `learnflow_v3/v376_native_manim_probe.py` injects a controlled monitor into the generated host Manim source at that exact boundary. The monitor runs **inside the existing no-network, read-only-root Docker sandbox** with a writable `/output` mount; it records actual runtime `get_bounding_box()` glyph/shape geometry converted using Manim camera dimensions to 1280×720 pixel coordinates, actual fill RGB/opacity, identity and frame tick serial/time, to `/output/v376_runtime_geometry.jsonl`. This is trusted host-injected code, never provider Python.

`learnflow_v3/v376_native_runtime_readability.py` rejects missing, inconsistent, skipped, duplicate or malformed tick rows, unsafe glyph/shape overlaps after excluding explicitly declared own-node labels, offscreen/NaN geometry, and actual Manim color-to-background relative luminance contrast under **4.5:1** on stable visible text. It requires a conservative match between runtime telemetry count and actual H264 video frame count. For independently decoded pixel samples, it reuses V3-45 physical H264 frame decoder to check 9 approximate time slices that a text bounding region contains real foreground pixels (not just a color declaration); correspondence is explicitly `APPROXIMATE_NOT_EXACT`, and **no universal frame-by-frame native pixel glyph verification** is claimed. All decoded motion frames outside this sample remain unproven; do not misrepresent source update ticks as guaranteed one-to-one rendered frames.

`scripts/run_v3_54_model_candidate_quality.py` now accepts a second default-off `runtime_v376` flag, which requires prior `strict_v375` preflight. It instruments the actual compiled source **before Docker**, then checks runtime telemetry and independent native H264 pixels **after mux and before success receipt**. Original V3-54 and V3-75 defaults remain unchanged. `scripts/run_v3_76_native_runtime_readability.py` repeats exactly the original three synthetic creative cases, records each versioned actual native MP4 and either `TECHNICAL_BOUNDED_PASS` or `NO_GO` with raw reason. A NO-GO (including low contrast) is a valid research result; no forced threshold changes. A real Docker probe must emit telemetry for CI to accept the trial as executed.
