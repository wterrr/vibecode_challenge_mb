# V3-25 — Independent Reviewer Instrument, Masked A/B Video, and Fail-Closed Response Audit

**Purpose:** implement a genuinely runnable instrument that independent reviewers could use on **two actual equal-resolution, equal-audio videos**, not another spreadsheet with fake human ratings. This checkpoint prepares an **exploratory diagnostic pilot**, **NOT** the V3-16 locked 12-topic confirmatory benchmark. No new participants recruited, no manual/fabricated responses, no paid API or product release. Stack only on V3-24 PR #58; preserve main and Frozen V2 Core.

## Reuse and strict scientific scope

- Reuse **two true source-matched MP4s**, V3-22 \`native_hd/v3_22_binary_search_native_720p.mp4\` and V3-24 \`native_pedagogical/v3_24_leftmost_teaching_720p.mp4\`. Both 1280×720, 24fps, 1082 decoded frames, identical H264 duration, original eSpeak AAC **identical packet bitstream**, V3-20 utterance/SRT physical event starts, same trace and target; only visual treatment changes. Actual media validation reruns \`verify_hd\` and \`verify_teaching_video\` and compares trace, SRT and event-proof SHA-256.
- The one **previously debugged/exposed Binary Search example is excluded** from confirmatory V3-01/16 12-topic sampling. Its ratings **cannot support V3 vs V2D generality, CI-based learning-gain claims, or 3Blue1Brown parity**. V3-16 human-participant authorization remains false and its frozen prereg JSON is never edited.
- Two anonymous slot codes R01/R02, each presented A and B but **with opposite order** via a deterministic seed locked before results. Exact candidate→label mapping is in admin-only JSON, outside each reviewer's folder. This is **masked-label**, not genuine double-blinding, because the 720p visual differences can reveal condition. No randomised population sampling, no power calculation; exploratory personal preference only.
- The entire viewer is a self-contained offline HTML file using two local H264/AAC MP4s. Reviewers can play both, rate each on nine concrete anchored 1–5 dimensions (including the V3-01 primaries **clarity** and **representation_adequacy**), enter physical screen inches and viewing distance, pinpoint a critical error timestamp, explain a rationale, and answer an unseen transfer question. **Transfer questions differ between A/B and viewing the first clip may teach the second**; those responses cannot prove a causal learning effect.
- Reviewer JSON is exported by the local browser without network, storage or account. The app can check both video players reached the end and require fields, but JS self-reports are **not cryptographic proof** the subject actually watched, is human/independent, or gave valid consent. The separate importer binds the self-report to code slot + assigned MP4 hashes and requires two independent, complete records before showing *descriptive* A/B scores. A third domain rater is flagged when 2-point disagreement occurs in either prereg co-primary dimension. Even two complete self-reports **never elevate** learner ready/release to PASS without separately verified independent assessment.
- Rater privacy: anonymous fixed codes, no names/email/IP collection or analytics; the ADMIN identity key must **never be sent to reviewers**. Its presence in a GitHub artifact is visible to repository collaborators and is not a secure randomisation server. As this is only exploratory and no raters are yet recruited, the question of real participant privacy/informed consent remains out of scope until separately authorized review.

## Implementation and expected exact outputs

- \`learnflow_v3/independent_quality_pilot.py\`: validates original *real* media, locked deterministic counterbalanced assignments, browser reviewer HTML, source/media hashes, reviewer package splitting, and a fail-closed submission importer. No human summary from generated test fixtures.
- \`scripts/verify_v3_independent_pilot.py\`: produces reviewer-only folders R01 and R02 (each containing only \`review.html\`, its anonymous metadata and two actual MP4s), plus admin-only identity key, withheld transfer-answer key and zero-response \`UNMEASURED/BLOCKED\` report.
- \`scripts/aggregate_v3_25_quality_responses.py\`: later offline ingestion of review JSON files from a separately authorized, consented participant process. Strong validation on the media hashes/slot, complete scores and values, notes/timestamps, duplicate IDs, and forged consent flags. The result stays self-reported and product release BLOCKED; no HTTP ingestion or human identity assertion.
- Tests \`tests/v3/test_independent_quality_pilot.py\` use **explicit synthetic in-memory submissions only as adversarial unit fixtures**; no such record is shipped as a human study outcome. They cover source-bound real video, complementary assignment, playable page, no result without responses, incomplete data, forged/duplicated packets, stale video hashes, absent observer notes/ratings, third-rater flags and the locked frozen V3-16 protocol.
- GitHub CI recreates the true V3-20/22/24 MP4s, verifies the A/B pair and runs all V3-25 mutation tests plus V3-24/V3-22/V3-20, Frozen V2/Hermes and prerequisite benchmark checks. It emits **four distinct artifacts**: reviewer R01 package, reviewer R02 package, admin-only mapping/evidence and raw source-matched MP4 proof. Separate artifacts limit *accidental* key mixing but **do not impose GitHub per-artifact access controls**; external distribution must preserve that separation.

## Locked acceptance / do-not-misrepresent policy

**Technical engineering PASS** is allowed only for exact PR-head CI and downloaded real-video/browser/evidence inspection. Human score / visual preference improvement / comprehension effect / licensing / publication are **UNMEASURED**, and \`participant_recruitment_authorized=false\` even if all technical gates pass. A reviewer's score without proof of independence and appropriate consent may be summarized as self-report only, never confirmation. No new samples, score thresholds or search/repair iterations after seeing outcomes without a clearly labeled new protocol. The V3-16 12-topic confirmatory benchmark and V3-17 production authority stay independently blocked.

**User action required for genuine human evaluation:** separately invite at least two independent consented reviewers, distribute **only their own** anonymous reviewer ZIP (not the admin ZIP), collect exported JSON privately, then rerun the offline importer and independently verify identity/consent and source review. Until these real responses exist, the scientific conclusion is **NOT_RUN**, not PASS and not negative.
