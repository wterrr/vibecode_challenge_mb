## Trace-grounded pedagogy and media assembly

- Authoritative input is a sorted integer sequence and target sent via the existing FastAPI test/development route. Generate `BinaryLessonSource` from real request values and target. Replay V3 trace oracle and original source-to-pixel Binary Search IntegratedClipReceipt; preservation/route/beat source hashes are held in the final new `NarratedLessonReceipt`.
- Authored stage ordering **INTRODUCTION → EXPLANATION → WORKED_EXAMPLE × all oracle steps → RECAP**; each stage has a distinct intelligible English utterance derived from source values/target and an exact certified beat ID, segment ID, claim `claim-01`, object `array-01`, step index and trace SHA. For every frame of every scene, reuse V3-06 `draw_binary_search_frame(trace,step_index,progress)`. The per-frame progress evolves throughout the actual spoken segment rather than holding/looping a three-second demo. A role-specific small top label and lower subtitles-safe band preserve continuous visual state, with final subtitles burned by original V2 assembler.
- For each scene, invoke local speech executable with the exact authored text; read WAV PCM frames, sample rate and RMS. Compute **frame_count=ceil((raw sample count / sample rate) × 12)+1** (≤1 frame safety buffer), derive scene timestamps from *exact cumulative frame counts*, pad the real speech WAV to this duration with FFmpeg (`apad`, never audio replacing speech), and record one exact subtitle cue from scene start until *measured raw speech end*. This is **segment-level boundary alignment**, not word/phoneme forced alignment or independent transcript-as-heard verification.
- V2 `ResolvedTimeline` validates strictly contiguous scene boundaries, subtitle source and measured speech duration; original `VideoAssembler` concatenates separate real H264 scene streams and separate padded WAV streams and burns the generated SRT. Output is H264 + actual audible AAC + SRT, initially assembled only to a PRIVATE `narrated.pending.mp4` in staging, with no public video URL.
- Verify original scenes' actual H264 and exact frame counts, final H264 + AAC streams, total duration alignment vs timeline and expected frames (≤1 frame codec tolerance), decoded audio RMS (overall and per speech-segment window), all output video frames decoded, exact SRT captions and times, source/beat IDs and final byte/SRT/checksum evidence. Immutable typed receipt forbids claiming human lexical evaluation, forced word alignment, publishing or global signal closure. Independent verifier replays source and subtitle text/times and rereads actual media.
- All temporary WAV/intermediate files live in `TemporaryDirectory`; only after media, subtitle, transcript/trace and visual QA PASS are final MP4, SRT and manifest hard-linked without overwrite.
