## Proposed falsification, registered before implementation

An initial first-tick stage marker must be emitted before and after scene membership, first object bbox, color, opacity, JSON serialization, and file flush. Runtime fields are recorded only in the scoped Manim observer and cannot be generated by source-only baselines.

**Phase 1:** A new trusted `scripts/run_v3_76r1_bounded_manim_probe.py` renders a tiny 1.25-second Manim scene with two Computer Modern Text and one RoundedRectangle through the same host `instrument` and unchanged **read-only, no-network, no secret** pinned `manimcommunity/manim:v0.19.0` sandbox. The subprocess has a HARD 45s cap (not another 340s blind rerun). It writes stage receipts, actual H264 metadata, physical first-tick telemetry row count and hashes to a new artifact directory. Missing bbox, first tick, H264 or >=15 nonempty valid telemetry rows is a **NO-GO**.

**Phase 2:** Only after minimal smoke succeeds, rerun original V3-76 three frozen creative SceneGraph cases with untouched 4.5:1 WCAG text contrast, text–shape intersection and native decoded-pixel tests. No case can be promoted on source-only telemetry. Any collision/contrast blocker remains a legitimate visual NO-GO; an instrumentation timeout is not evidence of visual defects.
