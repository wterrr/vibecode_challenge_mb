# V3-22 — Native HD Typography and Source-Grounded Pacing Retrofit

**Date:** 2026-10-09. **Branch:** chatgpt/v3-22-hd-typography-pacing, PR #56 stacked on V3-21 PR #55. Main and frozen V2 Core unchanged. No paid model call, new AI model, commercial release, approved public endpoint or participant evaluation.

## Motivation and source evidence

V3-21 [artifact #11589640300](https://github.com/wterrr/vibecode_challenge_mb/actions/runs/37867921350/artifacts/11589640300) proved the existing V3-20 narrated Binary Search video was 640×360 at 12fps, with very small 14–15px action overlays and captions. Its 10 utterance/event scene boundaries were correct but this did not prove legibility on a learner's device. Simple bicubic resizing of the old pixels would preserve unreadable glyph rasters and introduce no authentic intermediate motion frames.

## Implementation: reuse first

Reuses V3-05 oracle trace, V3-06 CPU Pillow + ffmpeg semantic renderer and installed Computer Modern Unicode fonts, V3-19 real eSpeak narration, V3-20 exact physical WAV/event boundary proof, V3-21 source/video/SRT decoder and QA logic. New local-only learnflow_v3/native_hd_lesson.py draws all image frames from original source trace at **1280×720, 24fps**. The identical source video/audio/SRT are regenerated by the existing V3-20 offline script for apples-to-apples comparison. This is a fresh draw at double clock cadence, **not** an FFmpeg image scale or frame duplication.

Every original V3-20 frame maps to exactly two HD frame times; event indices and audio/subtitle onset remain from the original physically sampled utterance proofs. Original AAC packets are copied unchanged via stream copy, with separate ADTS bitstream digests compared in source and resulting video. Word-level alignment / independent ASR transcript are **NOT claimed**.

Native overlays use OS-matched CMU Serif with an authored minimum 32px for main action and full caption text, natural line wrap to one or two lines measured with actual font bounding boxes. Two-line overflow and oversized single words fail instead of truncating. Semantic board pointers, array item identities, sorted values and prior bounds are redrawn from the immutable oracle, not inferred from upscaled pixels. Semantic motion schedule inside each APPLY phrase is hold 18% → state transition 62% → settle 20%; OBSERVE and RESULT never rewind the preceding settled state. This is a deliberate utterance-local cue, **not a discovered acoustic word onset**. Intro and recap retain their source-grounded index/visited-midpoint animations.

## Required actual-media verifier

A final source-grounded receipt and real H264+AAC MP4 must be written in private staging and linked only after validation. QA checks expected 1280×720, 24fps, double the source frame count, exact source/trace/event proof, original SRT SHA, unchanged AAC packet hash, 4 native-color sampled H264 frames per semantic event compared with freshly source-derived native image, and all three APPLY→OBSERVE/RESULT decoded continuous-state cuts using actual pixel ROI differences. Mutations must reject mismatched video and source, fabricated learning or publication PASS, missing outputs, caption overflow, accidental overwrite, forged proof and unsupported fallback. The contact sheet must be extracted from the **decoded native MP4**, not source raster or screenshots.
