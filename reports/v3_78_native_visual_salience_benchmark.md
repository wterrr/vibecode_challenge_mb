## New measurement-only implementation, not a style patch

`learnflow_v3/v378_native_visual_salience.py` audits the **actual in-Docker Manim scene object traces** from V3-76R1 SVG-leaf-provenance Text with V3-75's 1.07 conservative world-bbox reservation. For each approximate native update tick, it records exact (algorithmic, not pixel-filled) **UNION of scene-owned Text/Shape rectangular envelopes**, fraction of 1280×720 canvas reserved for content (median/p10/p90), content identity and scene-owned visible object count, longest periods where only persistent chrome exists, and per-identity visible text group height with a warning for native 24px threshold. Brand/title chrome excluded, and overlapping group rectangles not double-counted. The source metric is **NOT actual pixel foreground coverage**; child SVG bounding boxes are construct-time reservations and do not certify dynamic glyph points every encoded frame.

It independently decodes nine **real** H264 frames per movie via FFmpeg, verifies native frame byte SHA and checks a bound ROI foreground presence against dark canvas. This is a frame-sampled witness; telemetry-to-native frame relation is **approximate**, not word-alignment nor per-object exact pixel segmentation. No fabricated universal "salience" or 3B1B quality score. Existing 4.5:1 contrast and geometry validators are reused strictly.

`scripts/run_v3_78_native_salience_benchmark.py` reuses the original V3-77 true strict native 3-fixture render with no model API, then adds purely observational versioned receipts; source/storyboard/video unchanged by visual audit. `tests/v3/test_v3_78_native_visual_salience.py` has exact AABB union, non-double-counting, no-chrome-laundering, missing/duplicate runtime ticks, NaN/outside rect, no SVG fill provenance, empty content, corrupt video, fake decoder and no model quality conclusion. The dedicated pinned `.github/workflows/v3-78-native-visual-salience.yml` creates 3 fresh actual Manim H264/AAC, independently checks SHA/codec and 27 pixel samples and uploads scorecards.
