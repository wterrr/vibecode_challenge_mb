## Audit: actual creative pipeline, not a separate toy renderer

The existing V3-54 pipeline consumes a bounded mock model-shaped JSON candidate; `accept()` validates the provider-portable shape, evidence ledger, V2 SceneGraph topology and creative Storyboard; `creative_scene_graph.manim()` compiles HOST Python from trusted kinds/relations/actions; `_docker_manim()` generates real audiovisual graphics; native espeak/WAV and FFmpeg combine into H264/AAC; `creative_visual_quality_gate.inspect_native()` decodes native H264 pixels at 5 timestamps. Prior V3-54's sampled brightness/motion checks did NOT guard text/shape overlap, dynamic action geometry, or unexplained route intersection.

Unlike V3-74 Process, V3-54 accepts multiple scenes with PROCESS/COMPARISON/GRID/FREEFORM, SHAPE/TEXT/MATH/EQUATION/CHART, reveal/connect/emphasize/hide/move/replace. A safe generalized animation gate requires complete runtime Manim object occupancy; that exporter does not yet exist. This checkpoint therefore deliberately uses a **conservative, partial, fail-closed envelope** for static structural actions `reveal`, `connect`, and `emphasize` only. Any `move`, `replace`, `hide`, or unknown object fails the QA path before Docker rather than incorrectly earning PASS. V3-73 immutable Frame/Object per-frame timeline is reused with conservative envelopes for every node during each physical beat and a minimum 6px clearance. Edge route segments are measured against unrelated object rectangles using exact segment–AABB clipping, rather than checking just sparse route waypoints.

**Critical epistemic honesty:** these envelopes are not Manim runtime font glyph boxes (font metrics differ from Pillow); static over-reservation may reject otherwise safe scenes. Actual Manim text/shape overlap is **NOT_CERTIFIED** frame-by-frame by these proxies. Five decoded native pixel samples independently prove the newly rendered H264 visuals, audio/frames and temporal change, not arbitrary per-object collision absence. A structural geometry PASS must NEVER be promoted to general native visual-quality GO.
